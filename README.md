## 📌 Featured Projects

### 📈 Sales Performance Dashboard
An interactive **Power BI dashboard** built to give stakeholders a real-time view of revenue, margin, and regional sales performance.
- Connected and transformed raw sales data from SQL Server using **Power Query**
- Built custom **DAX** measures for YoY growth, margin %, and target tracking
- Designed drill-down visuals so teams can go from company-wide KPIs down to individual regions and products
- 👉 [View Project](https://github.com/bhavana-gaade/Sales-Performance-Dashboard)

---

### 👥 Customer Segmentation (RFM Analysis)
A Python-based customer segmentation project that identifies high-value customers using **RFM (Recency, Frequency, Monetary)** analysis.
- Engineered RFM scores from raw transaction data with Pandas and NumPy
- Applied **K-Means clustering (Scikit-learn)** to group customers into meaningful segments (loyal, at-risk, high-value, dormant)
- Visualized segment distributions and behavior patterns with Matplotlib and Seaborn to support targeted marketing decisions
- 👉 [View Project](https://github.com/bhavana-gaade/Customer-Segmentation-RFM-Analysis-)

---

### 🔄 ETL Pipeline with dbt & Airflow
An automated **ELT pipeline** that moves raw data from cloud storage into a warehouse and transforms it into analytics-ready tables.
- Pulled raw data from **AWS S3** and loaded it into **Snowflake**
- Modeled the data into a clean **star schema** using **dbt**, with tests and documentation built in
- Orchestrated and scheduled the full pipeline with **Apache Airflow**, including dependency management and failure alerts
- 👉 [View Project](https://github.com/bhavana-gaade/ETL-Pipeline-with-dbt-Airflow)
